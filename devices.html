Supported devices

57 Garmin AMOLED watches as of v2.1.0

RuckTrack runs on Garmin's AMOLED-display watches running Connect IQ 5.0 or later. The list below is grouped by product family.

If your watch isn't here, it's likely either a non-AMOLED model (RuckTrack is purpose-built for AMOLED contrast and doesn't ship on transflective displays) or pre-Connect IQ 5.0. The Connect IQ Store listing has the live compatibility check — install will only complete on a supported device.

Why AMOLED only

The six-screen design uses a deep-black AMOLED background as a structural element — the vibrant green dividers, the colored zone arcs, and the high-contrast numeric heroes all rely on the display's per-pixel light control. On a transflective MIP display, the same UI would lose its punch and the colored elements would muddy. Rather than ship a watered-down build, RuckTrack stays AMOLED-native.

Connect IQ version

RuckTrack builds against Connect IQ API 5.0. Most listed devices have firmware that supports newer Connect IQ features (action menus, in-place toggle items); a small number of older devices fall back to a 5.0-compatible code path automatically. You don't need to pick — the right path runs on the right device.
