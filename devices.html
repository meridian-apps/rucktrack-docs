If your watch isn't here, it's most likely a pre-Connect IQ 5.0 model. The Connect IQ Store listing has the live compatibility check — install will only complete on a supported device.

Display support

RuckTrack was designed AMOLED-first. The deep-black background, vibrant green dividers, colored zone arcs, and high-contrast numeric heroes all use the display's per-pixel light control. The MIP (64-color) and monochrome watches added in v2.4 can't render the photo-grade start screen, so on those displays it degrades gracefully to a clean flat layout, while the seven live screens, the numeric typeface, the charts, and every metric render the same. No watered-down build, just the right rendering for each display.

Connect IQ version

RuckTrack builds against Connect IQ API 5.0. Most listed devices have firmware that supports newer Connect IQ features (action menus, in-place toggle items); a small number of older devices fall back to a 5.0-compatible code path automatically. You don't need to pick — the right path runs on the right device.
